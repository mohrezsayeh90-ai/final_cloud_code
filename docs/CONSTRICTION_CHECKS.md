# بررسی مدل اصلی گاوسی با هندسهٔ جدید

این گزارش مربوط به نسخهٔ اصلاح‌شدهٔ **زمانی، دارای پارسل و کوپل دوطرفهٔ گاوسی** است.
برداشت قبلیِ جریان پایای بدون ذره در archive/FLUID_ONLY_CHECKS.md و commit be35186 حفظ شده است.
مسیر اصلی run_constriction.py و notebook اصلی اکنون مدل گاوسی را اجرا می‌کنند.

محیط بررسی Python 3.12 و PyTorch 2.6.0+cpu است. GPU وجود ندارد؛ سرعت و دقت اجرای CUDA آزمایش نشده‌اند.

## آزمون‌های سازگاری

فرمان python -m unittest discover -s tests -v مجموعاً ۳۷ آزمون دارد: ۳۴ مورد پاس و سه آزمون CUDA به علت نبود GPU skipped شدند.
آزمون‌های مربوط به مسیر جدید موارد زیر را بررسی کردند:

- با شعاع صفر، میدان و تمام باقیمانده‌های مدل دقیقاً با CoupledPINN اصلی برابرند؛ تلورانس مقایسه صفر است.
- دو شبکهٔ سیال و پارسل، تعداد پارامترها، جرم نمایندگی‌شده و مرکزهای اولیهٔ پیش‌فرض حفظ شده‌اند.
- شرط بدون لغزش روی قوس‌ها و دیواره‌ها و مرز تناوبی حفظ می‌شوند؛ شرط اولیهٔ هندسی واگرایی‌صفر است.
- داخل جامد از quadrature و نقاط معادلات حذف شده است.
- نرمال‌سازی کرنل، تبادل نیرو و تبادل کار روی همان quadrature سیال برقرارند.
- گرادیان‌های هر دو شبکه در float32 محدود و غیرصفرند.
- payload داخل notebook با سورس خوانا تطابق دارد و مسیر اجرای زمانی گاوسی را فراخوانی می‌کند.

## اجرای فنی چهار حالت قبلی

```bash
python run_constriction.py --device cpu --smoke --max-minutes 6 --train-minutes 0.8 --out /workspace/scratch/gaussian_constricted_smoke
```

زمان solver در بررسی‌ها حدود دو دقیقه بود؛ فقط سه گام آموزش برای هر حالت اجرا شد.
این زمان معیار عملکرد GPU نیست. باقیمانده‌های فیزیکی هنوز بزرگ‌اند و معیار کیفیت پژوهشی اجرا false است.
هیچ نتیجهٔ مرجع جای خروجی شبکه قرار نگرفت.

| خروجی | تعداد |
|---|---:|
| حالت‌های استوکس/بارگذاری قبلی | 4 |
| PNG | 48 |
| PDF | 48 |
| SVG | 48 |
| GIF زمانی، هرکدام ۱۲ frame در smoke | 8 |
| MP4 زمانی | 8 |

هیچ خطای رسم ثبت نشد. مسیرهای manifest، ماسک جامد در میدان‌ها، تعداد frameها، CRC و SHA-256 بسته بررسی شدند.
خطای نرمال‌سازی کرنل و تبادل نیرو کمتر از ۵×۱۰⁻¹⁶ بود؛ این عدد بررسی گسستهٔ تبادل نیرو است و درصد خطای مقاله نیست.
در این اجرای کوتاه مرکز پارسل داخل مانع نبود؛ این مشاهده تضمین عبور بدون برخورد در آموزش طولانی یا هندسه‌های دیگر نیست.

[بستهٔ کامل خروجی این بررسی](../deliverables/GaussianConstrictedPINN_CPUcheck_results.zip) شامل نمودارها، انیمیشن‌ها،
داده‌ها، checkpointها، تنظیمات و کد مربوط به همان اجرا است.
بستهٔ قدیمی BilateralConstriction_CPUchecks.zip متعلق به برداشت قبلیِ بدون ذره است و خروجی مدل گاوسی نیست؛ برای شفافیت حفظ شده است.

شرط اولیهٔ سیال برای هندسه سازگار شده است. فشار، موازنه‌ها و واکنش نیروی سیال شامل دیواره‌های خمیده هستند.
