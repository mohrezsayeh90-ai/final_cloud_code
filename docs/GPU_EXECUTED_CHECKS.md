# بررسی notebook و اجرای محدود GPU

تاریخ: ۲۰۲۶/۱۰/۱۵. محیط بررسی: Python 3.12، PyTorch 2.6.0+cpu.
در این محیط GPU وجود ندارد؛ اجرای واقعی CUDA، سرعت T4/A100 و کیفیت حاصل از ۳۵ دقیقه آموزش GPU **آزمایش نشده‌اند**.

## آزمون‌ها

`python -m unittest discover -s tests -v`: از ۲۱ آزمون، ۲۰ مورد پاس و آزمون اختصاصی CUDA به علت نبود GPU skipped شد.
آزمون‌های جدید سازگاری residual و gradient بین float32 و float64، حفظ checkpoint در پایان بودجهٔ زمان،
توقف کارگر با timeout، و تطابق کد داخل notebook با فایل‌های خوانای مخزن را بررسی می‌کنند.
آزمون CUDA در محیط دارای GPU، دو گام آموزش واقعی CUDA و بارگذاری checkpoint روی CPU را بررسی خواهد کرد؛ اینجا اجرا نشده است.

قالب notebook با `nbformat.validate` بررسی شده است. سلول‌های محاسباتی با `nbclient` در یک کپی موقت
با CPU و بودجهٔ smoke اجرا شده‌اند؛ بررسی وجود GPU فقط در همان کپی آزمایشی کنار گذاشته شده است.
notebook تحویلی همچنان GPU را الزامی می‌داند. نتیجهٔ ماشینی این بررسی در [GPU_NOTEBOOK_QA.json](GPU_NOTEBOOK_QA.json) است.

## بررسی مسیر کامل چهار حالت

فرمان اجراشده:

```bash
python run_gpu.py --device cpu --precision float32 --max-minutes 8 --train-minutes 0.8 --out /workspace/scratch/gaussian_gpu_four_case_check
```

این اجرا از اندازهٔ شبکه، quadrature و تعداد frame پیش‌فرض notebook استفاده کرد؛ فقط دستگاه CPU و بودجهٔ آموزش کوتاه بود.
زمان واقعی solver: **۲۴۸٫۴ ثانیه**. نتیجه مربوط به آزمون فنی کوتاه است و برای پیش‌بینی زمان/دقت آموزش GPU قابل تعمیم نیست.

| خروجی | تعداد |
|---|---:|
| حالت‌های کامل | 4 |
| PNG | 47 |
| PDF | 47 |

| GIF، هرکدام ۴۱ frame | 8 |

هیچ خطای رسم ثبت نشد. مسیر همهٔ فایل‌های manifest، تعداد frame انیمیشن‌ها، CRC داخل ZIP و SHA-256 بسته بررسی شدند.
مراحل آموزش، ارزیابی و export هر چهار حالت کامل شدند.
آزمون‌های تحلیلی V01–V10 پاس شدند؛ **معیارهای دقت کانال کوپل‌شده در هر چهار حالت پاس نشدند**.
تعداد اعتبارسنجی‌های مقاله‌ای این workflow برابر صفر است. شکل‌های اجرای کوتاه، نتیجهٔ معتبر مقاله‌ای فرض نمی‌شوند.

تمام فایل‌های این بررسی، شامل داده‌ها، تصاویر، انیمیشن، مدل‌ها، تنظیمات و کد، در
[بستهٔ نتایج آزمون CPU](../deliverables/GaussianParcelPINN_GPU_CPUcheck_results.zip) حفظ شده‌اند.
این بسته را با نتیجهٔ آموزش کامل GPU اشتباه نگیرید.

## محدودهٔ بررسی

وجود محدودکنندهٔ زمان و watchdog بررسی شده است؛ تکمیل همهٔ مراحل روی هر GPU یا در صورت قطع سرویس تضمین نمی‌شود.
بهترین checkpoint و وضعیت ناقص حفظ می‌شوند. محدودیت آموزش، مرحلهٔ ساخت شکل‌ها را حذف نمی‌کند؛ برای export بودجهٔ جدا رزرو می‌شود.
پس از پایان بودجهٔ یک مرحله، آن مرحله متوقف و وضعیت آن صریح ثبت می‌شود.
تصاویر ساختار شبکه، توزیع گاوسی و نمای عمق‌دار به‌صورت بصری هم بررسی شدند.
