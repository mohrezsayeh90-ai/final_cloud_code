# همان مدل پارسل گاوسی، با گرفتگی دوطرفه

Notebook اصلی این branch: [BilateralConstriction_GPU.ipynb](../BilateralConstriction_GPU.ipynb).
این فایل اکنون **مدل زمانی سیال–پارسل گاوسی قبلی** را اجرا می‌کند و فقط هندسهٔ کانال تغییر کرده است.
نسخهٔ قبلی که اشتباهاً جریان پایای بدون ذره را اجرا می‌کرد، در پوشهٔ archive و تاریخچهٔ Git حفظ شده است.
اسکریپت اصلی run_constriction.py اکنون مدل کوپل‌شدهٔ گاوسی را اجرا می‌کند.

## فیزیک حفظ‌شده

| بخش | همان مقدار و مدل قبلی |
|---|---|
| سیال | ناویر–استوکس تراکم‌ناپذیر دوبعدی و زمانی |
| کانال | L/H=3، ارتفاع 1، x تناوبی |
| محرک | نیروی حجمی x برابر 12/Re |
| Re و نسبت چگالی | 20 و 1000 |
| پارسل‌ها | 6 پارسل با شبکهٔ موقعیت و سرعت وابسته به زمان |
| درگ و واکنش | درگ استوکس؛ کوپل دوطرفه با همان کرنل گاوسی |
| عرض فیلتر | σ/H=.14، ثابت |
| گرانش مؤثر | (0,−.1) |
| مدت فیزیکی | tU/H از 0 تا 1 |
| حالت‌ها | low_inertia، baseline، high_loading، high_inertia |
| St | .08، .2، .2، .6 |
| بارگذاری اسمی | .05، .05، .15، .05 |
| برخورد | مانند پیش‌فرض قبلی، رقیق و بدون برخورد |

معادلات پارسل dq/dt=v و dv/dt=(U_G−v)/St+g و نیروی F=m_rep(U_G−v)/St همان‌اند.
واکنش سیال −ΣWᵢFᵢ است. U_G با همان وزن گاوسی از سیال نمونه‌برداری می‌شود.
فقط وزن اکنون روی ناحیهٔ سیالِ خارج از جامد نرمال می‌شود: W=χ_fluid G / ∫_fluid G.
تصاویر تناوبی x حفظ می‌شوند. تابع و عرض گاوسی، درگ و پخش نیروی واکنش عوض نشده‌اند.
شبکه‌های سیال و پارسل همان کلاس‌ها و اندازهٔ notebook قبلی را دارند؛ میدان سیال سه خروجی سرعت–فشار دارد.
تابع جریان فقط برای ساخت **شرط اولیهٔ سازگار با هندسه** استفاده می‌شود؛ شبکهٔ زمانی به مدل پایا تبدیل نشده است.

## تغییرهای لازم به دلیل هندسه

دو نیم‌دایره با r/H=.25 و x₀/L=.4 به دیواره‌ها اضافه شده‌اند؛ ارتفاع گلوگاه .5H است.
سلول اول فقط GEOMETRY با radius و center_fraction را برای هندسه تنظیم می‌کند.
طول، Re و پارامترهای فیزیکی همان مقادیر قبلی‌اند.
داخل موانع از نقاط معادلات و quadrature کوپل حذف می‌شود. شرط بدون لغزش روی قوس‌ها و دیواره‌های تخت سخت اعمال می‌شود.
عامل هندسی نزدیک انتهای دوره ثابت است و با ویژگی‌های تناوبی شبکه سازگار می‌ماند.
پروفیل اولیهٔ کانال صاف روی قوس‌ها بدون لغزش نیست؛ شرط اولیه با تابع جریان هندسیِ واگرایی‌صفر سازگار می‌شود.
دور از گرفتگی پروفیل اولیه بازمی‌گردد و در شعاع صفر میدان و معادلات دقیقاً به پیاده‌سازی قبلی برمی‌گردند.
فشار همچنان تناوبی با یک گیج است؛ محل گیج به نقطه‌ای تضمین‌شده در سیال منتقل می‌شود.

جرم نمایندگی‌شده و تعداد نمایندگی‌شدهٔ ذرات برای حفظ جرم قبلی تغییر نمی‌کنند.
با کاهش حجم سیال، نسبت واقعی جرم ذره به حجم سیال تغییر می‌کند؛ بارگذاری اسمی و مؤثر هر دو گزارش می‌شوند.
نرمال‌سازی گاوسی، انتگرال نیرو و تبادل کار روی همان quadrature سیال انجام می‌شوند.
موازنه‌ها شامل فشار و لزجت روی قوس‌ها هم هستند.
مراکز اولیه همان seed قبلی‌اند؛ فقط اگر مرکزی داخل مانع باشد بازنمونه‌برداری می‌شود و تعداد آن گزارش می‌شود.
برای هندسهٔ پیش‌فرض، مرکزهای اولیهٔ قبلی قابل استفاده‌اند.

## رفتار مرکز پارسل نزدیک مانع

مانند مدل قبلی، قانون برخورد یا بازتاب الاستیک اضافه نشده است. loss محصورسازی ورود مرکز به نیم‌دایره‌ها را جریمه می‌کند.
این قید نرم است؛ در آموزش ناکافی نفوذ ممکن است رخ دهد. شمار آن در گزارش و CSV می‌آید و در انیمیشن با دورخط قرمز مشخص می‌شود.
موقعیت‌ها clip یا به بیرون مانع project نمی‌شوند. کرنل، فیلتر کوپل با پهنای ثابت است؛ قسمت سیال آن دوباره نرمال می‌شود.
پارسل جسم جامد با شعاع فیلتر نیست. برخورد فیزیکی، روان‌کاری و گیرکردن به مدل دیگری نیاز دارند که در این اصلاح اضافه نشده است.

## اجرا و خروجی

در Colab، GPU را فعال و Run all کنید. کد و داده‌های تحلیلی لازم داخل notebook هستند.
همان هدف ۵۵ دقیقه و حداکثر ۳۵ دقیقه آموزش چهار حالت برقرار است؛ برای ارزیابی، شکل‌ها، GIF/MP4 و ZIP زمان جدا رزرو می‌شود.
آموزش float32 روی CUDA با Adam و checkpoint دوره‌ای و بدون AMP/TF32 است. رسم و ارزیابی روی CPU با float64 انجام می‌شود.
سقف زمان تضمین دقت یا تکمیل همهٔ مراحل روی هر دستگاه نیست. خروجی کم‌آموزش از بهترین checkpoint با وضعیت واقعی حفظ می‌شود.

ساختار دو شبکه، هندسه، میدان سرعت/فشار/ورتیسیته/کسر حجمی، snapshot زمانی، مسیر و سرعت پارسل‌ها،
ابر گاوسی، مقایسهٔ چهار حالت، پروفیل گلوگاه، انرژی و تکانه، سطح سرعت و نمای عمق‌دار تولید می‌شوند.
انیمیشن‌ها زمان فیزیکی پیش‌بینی‌شدهٔ سیال و پارسل هستند؛ اسکن میدان پایا نیستند.
PNG/PDF/SVG، CSV، NPZ، LaTeX، checkpointها، گزارش آفلاین و ZIP ساخته می‌شوند.
